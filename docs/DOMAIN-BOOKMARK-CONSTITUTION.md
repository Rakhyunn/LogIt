# DOMAIN-BOOKMARK-CONSTITUTION — 북마크 도메인 원칙

---

1. **북마크는 콘텐츠 접근점에 종속** — 북마크 추가/제거는 콘텐츠 목록 카드와 상세 페이지에서만 가능하다. 별도 `/bookmarks` 라우트는 두지 않는다. 북마크 목록 조회는 프로필 탭에서 제공한다.

2. **즉시 반응형 UX** — 북마크 토글은 Optimistic UI로 처리한다. 클릭 즉시 UI가 바뀌고 서버 요청은 백그라운드에서 처리되며, 실패 시 자동 롤백한다.

3. **북마크 작성/삭제는 인증 필수** — 북마크 액션은 로그인 유저만 실행할 수 있다. 비로그인 유저가 클릭하면 `/login`으로 리다이렉트한다. RLS가 `user_id = auth.uid()` 조건을 1차로 강제한다.

4. **목록 북마크 상태는 일괄 조회** — 콘텐츠 목록 페이지에서 유저의 북마크 상태는 카드별 개별 쿼리 없이 한 번의 쿼리로 일괄 조회하여 N+1 문제를 방지한다.

5. **ContentCard는 북마크 도메인을 모른다** — ContentCard는 `bookmarkSlot` render prop을 통해 외부에서 주입받은 UI를 렌더링한다. 북마크 로직은 ContentCard 내부에 포함하지 않는다.
